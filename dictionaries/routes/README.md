# Маршруты

Четыре файла — по одному на способ перевозки. Внутри не полный перебор пар,
а **сеть сегментов**: итоговый маршрут A→B собирается как путь по графу.
Это избавляет от комбинаторного взрыва и позволяет переиспользовать участки.

| Файл | Способ | Сегментов | Узлов |
| --- | --- | --- | --- |
| `routes_road.yaml` | `road` | 119 | 95 |
| `routes_rail.yaml` | `rail` | 106 | 89 |
| `routes_sea.yaml` | `sea` | 112 | 69 |
| `routes_air.yaml` | `air` | 200 | 89 |

## Схема

Все файлы используют одинаковый набор полей:

```yaml
- from: moscow
  to: kazan
  distance_km: 820
  duration_h: 14.6
  cost_per_ton_rub: 11020
```

- `from`, `to` — ID из `../locations.yaml`.
- `distance_km` — расстояние именно этим способом (не по прямой,
  кроме авиации).
- `duration_h` — время в пути, часы, включая обработку в конечных точках.
- `cost_per_ton_rub` — стоимость перевозки тонны, **целые рубли**.
- Все маршруты **двунаправленные** (`bidirectional: true`), поэтому каждая
  пара указана один раз.

## Как строятся маршруты

### Авиация (`routes_air.yaml`)
- Базовая схема — hub-and-spoke с `k = 2`: каждый не-хаб подключается
  к двум ближайшим хабам.
- Хабов 32: Москва, Санкт-Петербург, Новосибирск, Лондон, Париж, Франкфурт,
  Амстердам, Мадрид, Рим, Стамбул, Дубай, Каир, Йоханнесбург, Найроби,
  Дели, Мумбаи, Пекин, Шанхай, Гонконг, Сеул, Токио, Сингапур, Бангкок,
  Джакарта, Сидней, Нью-Йорк, Лос-Анджелес, Чикаго, Торонто, Мехико,
  Сан-Паулу, Буэнос-Айрес.
- Полёты короче 300 км исключены — для них используется наземный транспорт.
- Города ближе 300 км к хабу не имеют аэропорта (`airport: false`) и
  обслуживаются наземным транспортом соседнего хаба: Шэньчжэнь (27 км до
  Гонконга), Тяньцзинь (103 км до Пекина), Гуанчжоу (129 км до Гонконга),
  Рязань (182 км до Москвы), Барнаул (192 км до Новосибирска), Кемерово
  (204 км), Томск (207 км), Ярославль (250 км до Москвы).
- Две аномальные связи (Окленд → Джакарта, Мельбурн → Джакарта) удалены:
  у обоих городов остаётся Сидней.
- Хаб-сеть прорежена: прямая связь хаб–хаб оставлена, только если объезд
  через другой хаб длиннее не более чем на 10%.
- После чистки у 2 не-хабов (Окленд, Мельбурн) осталась одна связь вместо
  двух: короткие маршруты заменены наземным транспортом.
- Расстояние — по большой окружности.
- Формулы: `duration = distance / 800 + 2`, `cost = 30000 + 90 * distance`.

### Море (`routes_sea.yaml`)
- Только порты (`port: true`), включая речные/озёрные.
- Длинные линии разбиты по узловым портам: Роттердам, Гамбург, Стамбул,
  Дубай (Суэц, Баб-эль-Мандеб), Мумбаи, Сингапур, Шанхай, Владивосток,
  Нью-Йорк, Лос-Анджелес и др.
- `distance_km` — приближённые расстояния по реальным морским линиям
  через проливы и каналы (Гибралтар, Босфор, Суэц, Баб-эль-Мандеб,
  Ормуз, Малакка, Панама), а не по прямой.
- **Речные порты соединяются только внутри своей судоходной системы**
  (Волга с Окой, Камой, Вяткой, Белой; Обь с Иртышом и Томью). Выход
  в море допустим, только если речной порт стоит на границе «река-море»
  (Астрахань, Ростов-на-Дону, Салехард, Хошимин, Гуанчжоу) либо морской
  порт находится в устье той же системы (Роттердам для Рейна, Гамбург
  для Эльбы). Исключение — действующие каналы: Волго-Балтийский путь
  (Москва—Санкт-Петербург) и Волго-Донской (Волгоград—Ростов-на-Дону).
- Изолированные речные системы (Енисей, Лена, Амур, Селенга, Нил, Сена,
  Висла) **не имеют морских сегментов**: их устья не совпадают с портами
  сети, поэтому такие города выпадают из морского графа и обслуживаются
  ж/д, авто и авиа.
- Формулы: `duration = distance / 30 + 12`, `cost = 5000 + 2 * distance`.

### Ж/Д (`routes_rail.yaml`)
- Реальные коридоры и сухопутные переходы: Транссиб, БАМ/АЯМ,
  европейская сеть, переходы через Босфор, мосты и тоннели.
- Континенты не соединены искусственно: Америка, Австралия и отдельные
  азиатские сети образуют свои компоненты.
- Формулы: `duration = distance / 60 + 6`, `cost = 3000 + 6 * distance`.

### Авто (`routes_road.yaml`)
- Соседние города и известные магистрали, с учётом объездов, мостов
  и рельефа.
- Африка, Америка и Австралия — отдельные компоненты, как в реальности.
- Формулы: `duration = distance / 65 + 2`, `cost = 2000 + 11 * distance`.

## Пример сборки маршрута

Морская доставка Роттердам → Шанхай:

```
Роттердам → Стамбул → Дубай (Суэц, Баб-эль-Мандеб) → Шанхай
```

| Участок | Км | Часы | ₽/т |
| --- | ---: | ---: | ---: |
| Роттердам → Стамбул | 5500 | 195.3 | 16 000 |
| Стамбул → Дубай | 5900 | 208.7 | 16 800 |
| Дубай → Шанхай | 8000 | 278.7 | 21 000 |
| **Итого** | **19 400** | **682.7** (≈28 сут) | **53 800** |

Итоговые значения — сумма по сегментам (каждый сегмент включает свою
портовую обработку). Если пункт назначения не порт (например, Дели),
маршрут заканчивается в ближайшем порту (Мумбаи), а последняя миля
считается по ж/д или авто.

## Валидация

Компактный валидатор проверяет схему, счётчики, положительные числа и
разумные диапазоны, формулы времени/стоимости и связность графов:

```bash
python3 scripts/check_dictionaries.py   # отчёт, код выхода 1 при ошибках
python3 -m pytest tests/test_dictionaries.py -q
```

Минимальный пример самостоятельной проверки:

```python
import glob, math, yaml

loc = yaml.safe_load(open('dictionaries/locations.yaml'))['locations']
by_id = {x['id']: x for x in loc}


def great_circle(a, b):
    """Расстояние по большой окружности, км (WGS84, приближение)."""
    R = 6371.0
    p1, p2 = math.radians(a['lat']), math.radians(b['lat'])
    dp = p2 - p1
    dl = math.radians(b['lon'] - a['lon'])
    h = math.sin(dp / 2) ** 2 + math.cos(p1) * math.cos(p2) * math.sin(dl / 2) ** 2
    return 2 * R * math.asin(math.sqrt(h))


for path in sorted(glob.glob('dictionaries/routes/routes_*.yaml')):
    d = yaml.safe_load(open(path))
    routes = d['routes']
    assert d['bidirectional'] is True
    for r in routes:
        assert set(r) == {'from', 'to', 'distance_km', 'duration_h', 'cost_per_ton_rub'}
        assert r['from'] in by_id and r['to'] in by_id
        assert r['distance_km'] > 0 and r['duration_h'] > 0 and r['cost_per_ton_rub'] > 0
        # маршрут не может быть короче прямой; допуск 1 км — округление
        assert r['distance_km'] >= great_circle(by_id[r['from']], by_id[r['to']]) - 1, r
        if d['mode'] == 'sea':
            assert by_id[r['from']]['port'] and by_id[r['to']]['port']
        if d['mode'] == 'air':
            assert r['distance_km'] <= d['max_distance_km']
    print(path, len(routes), 'OK')
```

Стоимость и время — игровые оценки, а не биржевые тарифы; они в рублях,
поэтому не зависят от курса и легко пересчитываются без изменения структуры.
