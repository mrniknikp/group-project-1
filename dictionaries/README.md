# Словари проекта

Минимальные справочники для API и бизнес-логики транспортных компаний.
Все файлы — YAML, кодировка UTF-8, `schema_version: 3`.

## Состав

| Файл | Что внутри | Ключ |
| --- | --- | --- |
| `locations.yaml` | 100 городов/локаций (50 Россия + 50 мир) с GPS и инфраструктурой | `id` |
| `modes.yaml` | 4 способа перевозки — по одному на маршрутную сеть | `id` |
| `routes/` | 4 файла маршрутов — сеть сегментов по способам перевозки | `(from, to)` |

## Способы перевозки

| `mode` | Маршрутный файл |
| --- | --- |
| `road` | `routes/routes_road.yaml` |
| `rail` | `routes/routes_rail.yaml` |
| `air` | `routes/routes_air.yaml` |
| `sea` | `routes/routes_sea.yaml` |

Техника, грузоподъёмность и условия груза **не моделируются**. Заявка несёт
только пункт отправления, пункт назначения, вес и список разрешённых
способов; подходит способ или нет — решает отправитель. Чем именно везти
внутри способа — дело перевозчика.

## Конвенции

- **ID стабильные**: используются в API и заявках; менять нельзя, только добавлять новые.
- **Координаты**: WGS84, десятичные градусы (`lat`, `lon`).
- **Локация**: `port`, `airport`, `railway`, `road_access` — булевы признаки
  доступной инфраструктуры. `port` объединяет морские и речные порты.
- **Способ перевозки**: `mode` задаёт маршрутную сеть; отдельного поля
  «транспорт» нет.
- **Деньги**: только рубли, только целые числа. В маршрутах —
  `cost_per_ton_rub`, в API и сообщениях — поля с суффиксом `_rub`.
  Курсов валют и пересчёта в справочниках нет.
- **Доступность маршрута**: у обеих локаций должен быть нужный
  инфраструктурный флаг (`road_access` / `railway` / `airport` / `port`).

## Пример заявки

```yaml
request:
  origin: moscow          # id из locations.yaml
  destination: vladivostok
  allowed_modes: [rail, road]   # id из modes.yaml
  weight_t: 18.5
  response_deadline: 2026-11-12T18:00:00Z
```

## Валидация

```bash
python3 scripts/check_dictionaries.py   # отчёт, код выхода 1 при ошибке
```

Компактный валидатор проверяет схему и типы, уникальность id и пар, ожидаемые
размеры, положительные числа и разумные диапазоны, формулы времени/стоимости
и связность графов. Тесты — `tests/test_dictionaries.py`.
